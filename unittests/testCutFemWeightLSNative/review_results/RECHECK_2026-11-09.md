# QUAD/TRI recheck — 2026-11-09

Numerical validation passed for the tested 2D scope. Performance remains mixed, with the remaining regressions recorded below. The starting submission was `1a4c2c5fefa6a783fe27c1e2132073307e839314`; the preserved `rifat` benchmark is `0ff0669494e603be248d02c44c0a2e9b81f72b4d`. All integrated monomial tests are capped at total degree 10. Only three production headers changed.

## Corrections

1. Mapped tangency weights now use a discriminant evaluated in the local strip coordinate with the known endpoint factors retained. This avoids subtracting nearly equal numbers in the delta denominator. The cached factorization is reused by adaptive children and both quadrature rules.
2. Stationary boundary intersections and discriminant events describing the same tangency now share one event. This removes artificial microscopic panels after floating-point coordinate transformations. Genuine distinct intersections remain separate.
3. QUAD weak graph patches now call the shared mapped LINE integrator. Native reference quadrants retain the derivative-guided subdivision path before Taylor or full GK.
4. TRI keeps the inexpensive whole-element graph attempt, limits that attempt to eight refinement levels, and integrates unresolved cells directly on the standard reference triangle. Direct moments avoid the conservative amplification and cancellation caused by converting through ordered and diagonal charts. Surface gradients stay in the matching coordinates.
5. The TRI circle probe now checks analytic mass and area and returns a failure status on any failed case. The fallback regression uses a field that actually exercises fallback after the stronger graph rule. The benchmark expects all 108 timing cases. Sanitizers stop on undefined behavior, and CI clears previous acceptance before testing and uploads its evidence.

Before correction, four TRI small-circle requests failed at `1e-12`. An added QUAD ellipse test also exposed a delta-mass error of `3.70486448e-8` for a `1e-12` request: computed `2.752079695375229`, exact `2.752079658326584`. Both regressions now pass.

## Reproduce

From `unittests/testCutFemWeightLSNative`:

```sh
python3 build.py --jobs 2
python3 run_focused.py --extended
python3 run.py --selection original
python3 run.py --selection supplemental
python3 compare_planar.py
python3 run_review_validation.py
```

Boost, Eigen 3, NumPy, and mpmath are required. `BOOST_INCLUDEDIR`, `EIGEN3_INCLUDE_DIR`, and `CXX` select dependencies. The final-validation workflow runs these checks and prints the validation and comparison summaries. Its acceptance is reset before the build and becomes true only after the numerical, sanitizer, mesh-refinement, and paired-moment checks complete.
